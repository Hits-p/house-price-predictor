🏠 House Price Prediction App using Linear Regression
📌 Overview

This is a simple machine learning web application built using Streamlit that predicts house prices based on house size. The app trains a Linear Regression model on synthetically generated data and provides real-time predictions along with interactive visualizations.

🎯 Objective

Demonstrate the working of Simple Linear Regression

Build an interactive ML application using Streamlit

Visualize the relationship between house size and price

Provide real-time predictions based on user input

🛠️ Tech Stack

Python

Streamlit

NumPy

Pandas

Scikit-learn

Plotly

📊 Working

Synthetic house data is generated using NumPy

Data is split into training and testing sets

A Linear Regression model is trained using Scikit-learn

User enters house size through the UI

The app predicts the house price

Prediction is visualized on an interactive scatter plot

🚀 Features

Interactive web interface

Real-time model training

User-controlled input

Price prediction with clear output

Interactive scatter plot with highlighted prediction

🧪 Dataset

The dataset is synthetically generated

Features:

size — House size (sq. ft.)

price — House price

Noise is added to simulate real-world data
